# Smart Quiz System

A simple console-based **Quiz Management System** developed in **C++**. The system allows admins to register users, teachers to create quizzes, and students to attempt quizzes with automatic grading.

## Features

- Admin login
- Teacher and student registration
- Teacher quiz creation
- Student quiz attempt
- Randomized questions
- 60-second quiz timer
- Automatic score and grade calculation
- Results stored in a text file

## Technologies Used

- C++
- File Handling
- Structures
- Chrono Library
- Standard Template Library (STL)

## How to Run

Compile:

```bash
g++ main.cpp -o quiz
```

Run:

```bash
./quiz
```

On Windows:

```bash
quiz.exe
```
